# Aprendendo Git

Repositório de prática usado para aprender os comandos do Git e o fluxo com o GitHub. Os arquivos HTML são só conteúdo de teste para gerar alterações.

## O que foi praticado

O histórico de commits mostra cada exercício:

- Primeiro commit e envio para o GitHub (`git add`, `git commit`, `git push`)
- Desfazer um commit com `git revert`
- Corrigir o último commit com `git commit --amend`
- Ignorar arquivos e pastas com o `.gitignore`
- Trazer alterações do remoto e resolver um merge (`git pull`)
- Incorporar um Gist em uma página HTML (`index2.html`)

Veja os passos em [Commits](https://github.com/cgb102000/aprendendoGit/commits/main).
